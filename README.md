# Han Zhang — personal research website

[zarad0x.github.io](https://zarad0x.github.io/)

A minimal, dark academic homepage with a bilingual blog. Built with Astro and TypeScript; published by the existing GitHub Actions → GitHub Pages workflow.

## Development

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`npm run build` checks Astro/TypeScript before generating the static site. The Pages workflow uses the committed npm lockfile and builds from `main`.

## Editing

- Homepage biography, availability, selected publication: `src/pages/index.astro`
- Contact and social links: `src/consts.ts`
- Research experience: `src/content/work/*.md` (shared by the homepage and `/work/`)
- Blog posts: `src/content/blog/`; English and Chinese versions share a `translationKey`
- Project details: `src/content/projects/`
- Typography and responsive layout: `public/style.css`
- Shared layout, navigation and metadata: `src/layouts/` and `src/components/`

Use ISO dates such as `2026-10-24` so publication dates remain consistent across local and CI time zones. Set `draft: true` to keep an entry unpublished. Existing draft/template content and the original article Markdown are retained. `/work/`, `/projects/`, `/projects/freeartgs/`, `/blog/`, and both article languages remain available. RSS, robots.txt and the sitemap are generated by Astro.

## Assets and fonts

The FreeArtGS teaser was supplied by Han Zhang. The site self-hosts Inter, Newsreader, and a Noto Serif SC subset; SIL Open Font License notices are included in `public/assets/fonts/`. The Chinese font subset covers the currently published essay; new characters fall back to the reader's system fonts. Regenerate the subset from the OFL source font when adding substantial Chinese content.

The 2026-11-05 redesign was migrated from the reviewed Sites version, retaining the original Git history and GitHub Pages deployment workflow. The Astro Nano template's original MIT license is retained in `LICENSE`.
